# SOC-01

## System Overview

| Parameter | Value |
|---|---|
| Hostname | soc-01 |
| Operating System | Ubuntu 26.04.1 LTS |
| Virtualization | VMware |
| Network | VMnet2 |
| IPv4 Address | 192.168.100.10/24 |
| Role | SOC / Security Monitoring |

## Purpose

SOC-01 is the primary security monitoring system within
the laboratory.

It will be used to collect, analyze and investigate
security-related telemetry generated by the laboratory
systems.

## Planned Responsibilities

- SIEM operation
- Log collection and analysis
- Security alert monitoring
- Detection investigation
- Incident analysis
- Incident response documentation
- Security evidence collection
- GRC analysis

## Network Configuration

The laboratory network is based on:

192.168.100.0/24

SOC-01 uses:

192.168.100.10/24

The production testing environment is intended to operate
on the isolated VMware laboratory network.

## Temporary Internet Connectivity

Internet connectivity was temporarily enabled during the
initial setup phase to install system updates and required
software.

The laboratory will use the isolated lab network for
security testing.

## Planned Security Technologies

SOC-01 is planned to host or manage security monitoring
components including:

- Wazuh
- SIEM tooling
- Security log analysis
- Network security monitoring
- Investigation tooling

Additional security tools will be introduced as the
laboratory develops.

## Evidence

System configuration, network configuration, security
tool deployment and relevant test results will be
documented as project evidence.
