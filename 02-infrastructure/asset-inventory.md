# Asset Inventory

## Purpose

The asset inventory provides a structured overview of the
systems that form the cybersecurity laboratory.

Asset identification is the foundation for subsequent
risk assessment and security control selection.

## Asset Classification

### SOC-01

Security monitoring infrastructure responsible for
collecting and analyzing security telemetry.

### SRV-01

enterprise asset.

### ATTACK-01

Controlled security testing system used exclusively against
the laboratory environment.

## GRC Relevance

The asset inventory will be used as the foundation for:

- Threat identification
- Risk assessment
- Security control selection
- Incident impact analysis
- NIST CSF mapping
